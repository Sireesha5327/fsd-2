# FSD-2 Backend

This directory contains the Express.js backend examples. Each project keeps its own `package.json` and start script.

Projects:
- `express_middleware_api`
- `mongodb-express-app`
- `mongoose_express_app`
- `mvc_express_app`

The root `server.js` is a small Express entry point. Install root dependencies with `npm install` and run it with `npm start`.

For each example, open its folder, run `npm install`, configure environment variables locally, then run `npm start`.

Do not commit `.env` files or `node_modules`.
